# Bedding Designer AI

Public source snapshot for the pattern-design web application. The `.env` file from the private repository is omitted. Create `.env.local` from `.env.example` and supply configuration for a Supabase project you control. Never commit real credentials.

## Development

Install Node.js, run `npm ci`, then use the scripts in `package.json`.

This repository contains application source only. It does not grant access to any hosted Supabase project or AI service.
